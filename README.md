# Notely

Landing hero for Notely, an AI app that records meetings, writes summaries and turns agreements into tasks.

Static site: `index.html` plus `assets/`. No build step.

- Scroll drives the hero: sequins form the "n", melt into a moving blob, drift right, turn into letters that ride a track into the captions, then evaporate as the headline is typed.
- The sequins react to the cursor; a white smoke trail follows it.
